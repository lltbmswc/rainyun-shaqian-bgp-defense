## 快不快、扛不扛打：京东云 BGP 与 150G 独享

宿迁走的是京东云 BGP 线路，国内访问延迟低，这一点在第三方整理的响应速度排序里排第一：宿迁 > 十堰 ≈ 宁波 > 香港 3 区 > 香港 4 区 > 洛杉矶 2 区 > 洛杉矶 1 区。

防御是宿迁真正的差异化。公网独享 150G 高防是雨云全线产品里最高的一档，能和它并列的只有洛杉矶 2 区那个可选 200G 高防的版本。国内其他节点里，宁波和十堰给的是 100G 级别。买宿迁的独立 IP，防御是独享的；用 NAT 共享 IP 时，150G 由同一 IP 上的多个用户共同分担，别人被打你也会受影响。

带宽这一项要泼点冷水。第三方把公网带宽的排序列为洛杉矶 1 区 > 宁波 > 宿迁 > 十堰 > 洛杉矶 2 区 > 香港 4 区 > 香港 3 区，宿迁排第三，属于中上水平，但低于宁波。宿迁机型的常见口径是 5～15M 上传、100M 下载，做视频站、下载站这类吃上行带宽的业务，宁波更合适。

网络稳定性会有些反直觉。排序是宁波 > 十堰 > 宿迁 > 洛杉矶 2 区 > 香港 3 区 > 香港 4 区 > 洛杉矶 1 区，宿迁排第三，宁波略优。如果你的业务对抖动极其敏感，宁波是更稳的选择；能接受偶发波动换取更高防御和更低延迟，宿迁更值。

CPU 是宿迁的另一张牌。游戏云用的是 AMD Ryzen 9950X（Zen5、4nm、16 核 32 线程、最高 5.7GHz）和 Intel 14900K（最高 5.8GHz），这类消费级旗舰的单核性能远高于常见的 E5 系列服务器 CPU。有 Minecraft 服主用 4核8G 的 9950X 跑 100 人在线、1.20 版本，TPS 稳定在 19～20。第三方对 4核8G 宿迁 9950X 的测评记录里，LemonBench 单核 6849.72 分、多核 27126.24 分，Geekbench 6 单核 2939、多核 8502。

## 下单前必须算清的三笔账

**第一笔，独享 IP 150 元/月。** 这是全文最容易被忽略的数字。海外节点的独立 IP 是 5 元/个/月，香港移动高防 IP 是 40 元/月，宿迁因为带 150G 防御，直接跳到 150 元/月，比服务器本身还贵。宿迁不少套餐默认是 NAT 共享公网 IP，只能开 10～15 个端口映射，拿来学 Linux、做内网穿透、开游戏私服够用，但不能直接搭网站。

**第二笔，备案约 20 天。** 宿迁属于国内节点，绑定域名对外提供网站服务必须先备案，第三方记录的周期在 20 天左右。只跑数据库、做学习研究、写程序这些用途，不需要备案，也不需要独立 IP。想跳过这一步只能选香港或海外节点。

**第三笔，上传带宽的实际上限。** 5～15M 上行决定了宿迁不适合大流量分发型业务。流量超限后会被限速到 5M（部分机型描述为 1M），不会直接停服，恢复需要买流量包，价格大约 100 元/1TB 到 200 元/1TB。硬盘扩容另算，固态 0.3～0.4 元/GB/月，机械 0.1 元/GB/月，多数套餐默认 30GB。

还有一个使用层面的细节值得提。有作者在 2026 年 3 月的文章里说，选宿迁节点部署 AstrBot 后 WebUI 打不开，在官方交流群得到的解释是某些地域的服务器对海外 IP 或特定端口访问可能存在限制，而 AstrBot WebUI 默认端口可能正好在受限范围。这只是一个面板、一个端口的单一案例，不能推广成“宿迁屏蔽所有海外访问”，但如果你的业务依赖远程面板访问，先用 1 元试用跑一天验证一下更稳妥。该文推荐的“上海”“广州”节点在雨云其他资料里查不到，可以忽略。

## 真实年成本：32 元的机器配上 150 元的 IP

以宿迁 2核2G 标准套餐为例。月付 32 元，加独享 IP 150 元，每月实际支出 182 元。机器走年付七折是 268.8 元/年，IP 按 150 元/月×12 算是 1800 元，一年总支出约 2069 元。也就是说，在这套配置里，IP 占了总成本的 87%。

只跑数据库、学习研究、内网服务，不绑定域名对外建站，就不用买独立 IP、不用备案，年付 268.8 元就能拿下一年。两条路径差了将近 1800 元，选之前先想清楚这台机器到底要不要对外提供网站服务。

游戏云是另一种算法。9950X 2核4G 月付 112 元，年付七折 940.8 元。动态计费模式下计价单位是 0.001 元/电量，玩家下线超过设定时长（可设 5～60 分钟）无人在线就停止计费。只在晚上和周末开服的玩法，月开销可能明显低于固定计费；24 小时长开、CPU 长期高占用的服，固定计费更省。

## 宿迁、宁波、十堰、香港怎么选

按需求对号入座就行。

要高防 + 低延迟 + 已有备案域名，选宿迁。150G 独享防御、京东云 BGP、国内延迟最低，对应的是被攻击风险高、用户集中在国内的业务。

要大带宽做视频站、下载站、网盘，选宁波。50M、100M 甚至 500M 的带宽选项，硬盘能扩到 2TB，稳定性排序还在宿迁之上，代价是防御级别低一档、延迟略高。

预算有限但要 100G 防御，看十堰。电信单线、100G 高防，可选流量计费模式，最低配置就有 50Mbps 上行和 100Mbps 下行，价格比宿迁便宜。

不想备案、面向亚太用户，选香港。香港 4 区 2核4G、20M 带宽、1024GB 月流量，第三方测评记录月付 43 元，免备案，软银线路带宽宽裕，适合有图有视频的站点。

## 几个常被问到的问题

**宿迁必须备案吗？** 绑定域名对外提供网站服务必须先备案。数据库、学习研究、跑程序这类用途不需要备案，也不需要独立 IP。

**独享 IP 一定要买吗？** 建站要。NAT 共享 IP 只能开 10～15 个端口映射，做不了 80/443 的网站服务。开游戏私服、做内网穿透、学 Linux 可以不买。

**宿迁能装 macOS 吗？** 不能。支持 macOS 的只有香港 2 区、香港 4 区和湖北十堰。Linux 和 Windows 全机房都能装，宝塔、1Panel 可以一键部署。

**流量超了会怎样？** 限速到 5M，部分机型描述为 1M，不会停服。恢复高速要买流量包，约 100～200 元/1TB。

**和阿里云、腾讯云差在哪？** 差在品牌背书和 SLA 层级。单机性能同价位不落下风，价格通常低 20%～50%，年付折扣不像大厂那样首年便宜、续费翻倍。
